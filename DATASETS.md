# AGRISAATHI datasets and reproducibility

Large datasets, model artifacts, and reports are ignored by Git. This document
records the currently acquired crop data and the still-pending disease-data
workflow. Do not use an unverified mirror or bypass source terms.

## Reproduce crop acquisition and training

Run these commands from the repository root. The downloader safely handles a
CSV or ZIP archive, records source metadata, and never commits the result.

```powershell
python ml/scripts/download_crop_dataset.py
python ml/scripts/prepare_crop_dataset.py --drop-invalid --drop-duplicates
python ml/training/train_crop_model.py
```

Outputs:

| Output | Purpose |
| --- | --- |
| `ml/datasets/crop/raw/source_manifest.json` | Source URL, timestamp, file hash, reported license note. |
| `ml/datasets/crop/processed/manifest.json` | Schema, input/output hashes, cleaning counts, class counts. |
| `ml/models/crop_model.joblib` | Trained artifact, ignored by Git. |
| `ml/models/crop_model_metadata.json` | Artifact hash, feature order, classes, model version, provenance. |
| `ml/reports/crop/metrics.json` | Measured held-out evaluation metrics. |

The inference helper refuses a missing, schema-incompatible, or checksum-mismatched artifact:

```powershell
'{"N":90,"P":42,"K":43,"temperature":25,"humidity":80,"ph":6.5,"rainfall":200}' |
  python ml/inference/crop_predict.py
```

## PlantVillage acquisition and validation (not yet a model pipeline)

The only currently implemented disease-data scripts are:

```powershell
# Prints the source plan without cloning.
python ml/scripts/download_plantvillage.py --dry-run

# After the operator has reviewed and accepted source terms:
python ml/scripts/download_plantvillage.py --accept-source-terms

# Detect corrupt files and exact duplicate hashes; it never deletes images.
python ml/scripts/validate_plantvillage.py
```

`download_plantvillage.py` performs a sparse Git checkout of `raw/color` and
records the resolved source revision. `validate_plantvillage.py` writes a report
with valid/corrupt image counts, dimensions, class counts, and duplicate groups.

There is deliberately no PlantVillage split, disease training, disease artifact,
or disease inference script yet. Do not expose a diagnosis before those stages
exist, are evaluated, and are documented.

## Data safety

- Keep source images, farm uploads, SQLite data, artifacts, and reports outside
  public static paths and out of Git.
- Preserve source URL/revision, license/terms evidence, hashes, preprocessing,
  split seed, package versions, and measured metrics for every model run.
- Do not combine datasets with different label taxonomies/capture conditions
  without a documented rationale and leakage check.
- Treat user crop images and farm profiles as private data; define retention,
  deletion, backups, and access control before multi-user deployment.
